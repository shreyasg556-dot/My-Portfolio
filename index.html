PROJECT SPECS // ADAPTIVE HEADLIGHTS
DOMAIN: Embedded Systems • IoT
TIMELINE: Oct 2024 (30-Day Sprint)
ROLE: Sole Lead Developer
STATUS: Working Prototype Verified

PROBLEM STATEMENT

On dark, winding roads and highways, conventional high-beam headlights frequently cause severe optical glare for oncoming motorists, triggering temporary blindness and causing serious collisions. Concurrently, static headlights fail to adequately illuminate road curves ahead of steering initiation.

ENGINEERING ARCHITECTURE

Engineered in low-level C on a microcontroller platform. Implemented ambient Light-Dependent Resistors (LDRs) positioned with optical baffles to detect oncoming headlamp lux levels. Programmed an analog comparator loop with debounce and moving-average thresholds to prevent light flicker. Integrated a precision servo motor mechanism that dynamically swivels headlight angles in real-time according to curved steering trajectories.

TECHNOLOGY STACK

C Programming Embedded Systems LDR Sensors Servo Actuators Analog I/O Microcontroller Flashing

LANGUAGE: Java (OOP)
COMPLEXITY: O((V + E) log V) Dijkstra
STATUS: Algorithm Verified

ALGORITHMIC SCOPE

Constructed to demystify complex graph traversal mechanics. Models 2D matrix grids as weighted adjacency graph structures, enabling real-time comparisons between uninformed searches (Breadth-First Search, Depth-First Search) and informed heuristic searches (A* Search and Dijkstra's Shortest Path).

KEY IMPLEMENTATIONS

Utilizes a custom Priority Queue with min-heap ordering for Dijkstra and A*. Supports dynamic wall generation, recursive backtracker maze generation, and heuristic cost switches (Manhattan distance vs. Euclidean distance).
